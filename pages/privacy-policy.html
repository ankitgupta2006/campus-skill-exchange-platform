PRIVACY

Your information,
handled responsibly.

This policy explains what Campus Skill Exchange collects, how it is used, and how WhatsApp contact information is protected.

Last updated: September 2026

1. Information We Collect

When you create an account, the platform may collect your name, email address, college, course or department, skills you can teach, WhatsApp number, and password.

2. How We Use Information

Your information is used to create and display your student profile, help students discover skills, authenticate accounts, manage exchange requests, operate the dashboard, and support communication after an exchange request is accepted.

3. WhatsApp Number Privacy

Your WhatsApp number is collected during registration but is not intended to be publicly displayed to every visitor. It remains hidden while an exchange request is pending.

After an exchange request is accepted, the connected student may receive access to the relevant WhatsApp contact and use the direct WhatsApp link provided by the platform.

4. Authentication and JWT

The application uses JSON Web Tokens (JWT) for authentication rather than server-side sessions. Passwords are not stored as plain text; the backend hashes passwords using bcrypt before storing them.

JWT secrets and other private configuration should be stored in environment variables and must not be committed to source control.

5. MongoDB and Data Storage

Account, profile, and exchange-request data are stored using MongoDB through Mongoose. Local development can use MongoDB Community Server. A production deployment should use a secured, access-controlled database service.

6. Data Security

The project uses password hashing, JWT authentication, protected API routes, environment variables for secrets, and a Git ignore configuration intended to keep private configuration out of the repository.

Users should never share their password, JWT token, or private account credentials with others.

7. Third-Party Communication

When you use a WhatsApp contact link, communication takes place through WhatsApp. WhatsApp's own privacy practices and terms apply to that communication.

8. User Responsibility

Only provide information you are comfortable sharing through the platform. Do not post another person's private information without permission.

9. Data Changes and Deletion

Profile information can be updated through the dashboard where supported. A future production version may add dedicated account deletion and data-export controls.

10. Changes to This Policy

This Privacy Policy may be updated when the application's features, data practices, or security measures change. The latest version will be published on this page.
